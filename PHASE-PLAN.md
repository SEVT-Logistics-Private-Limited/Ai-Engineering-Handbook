# MVP Phase Plan

## Phase 1 — First-principles MVP

Goal: prove the structure, learning order and strict separation between conceptual explanations and project evidence.

### Shared foundations
- [ ] Data, information and modalities.
- [ ] Analog versus digital representations.
- [ ] Bits, bytes, binary and file formats.
- [ ] AI / ML / deep learning / generative AI distinctions.
- [ ] Basic arrays and tensors.

### Text MVP
- [ ] Text, characters and documents.
- [ ] ASCII, Unicode and UTF-8.
- [ ] Tokenization, vocabulary and token IDs.
- [ ] Embedding fundamentals.
- [ ] Transformer and attention fundamentals.
- [ ] GPT-style LLM training/inference overview.
- [ ] Text-to-text I/O and a basic RAG architecture.

### Image MVP
- [ ] Pixels, channels, RGB, dimensions and formats.
- [ ] Decode, resize, crop and normalize.
- [ ] Basic computer-vision model flow and classification.
- [ ] Image-to-label and introductory image-to-text paths.

### Audio MVP
- [ ] Sound, sampling, sample rate, bit depth, channels and waveform.
- [ ] Audio decode, resampling and segmentation.
- [ ] STT and TTS pipeline concepts.
- [ ] Audio-to-text and text-to-audio I/O.

### Video MVP
- [ ] Frames, FPS, timestamps and codecs.
- [ ] Decode video and extract/sample frames.
- [ ] Basic frame-based video-to-text workflow.

### Multimodal MVP
- [ ] Modality-specific representations and combined inputs.
- [ ] VLM fundamentals.
- [ ] Image + text → text flow.
- [ ] Basic grounding and cross-modal failure cases.

### Project-evidence MVP
- [ ] Record supplied project identity, scope and repository links.
- [ ] Build Tiny GPT evidence pages after source review.
- [ ] Build Telugu STT/TTS evidence pages after architecture details are supplied.
- [ ] Build YODA agent/workflow evidence pages after system details are supplied.
- [ ] Keep unknown contribution, stack and metrics as `TODO: supply`.

## Later expansion

- Advanced sequence-model history and architecture comparisons.
- Advanced image detection, segmentation, OCR and visual retrieval.
- Video temporal modeling, tracking and video generation.
- Advanced audio models, diarization, voice conversion and audio generation.
- Advanced multimodal fusion, omni models, multimodal RAG and agents.
- Fine-tuning methods, LoRA, quantization, distillation and distributed training.
- Evaluation benchmarks, safety, production deployment, monitoring and cost optimization.

## Phase 1 definition of done

Core foundations and modality MVP paths have concept pages; every project claim has either a linked evidence page or an explicit `TODO: supply`; all cross-links work; and a reader can follow the path from README to each topic.
