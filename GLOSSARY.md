# AI Engineering Glossary

A growing plain-language dictionary. Add terms as they appear in topic pages.

| Term | Short explanation |
|---|---|
| Analog signal | A continuously varying physical signal, such as air pressure in sound. |
| Digital data | Information represented using discrete values, commonly bits. |
| Bit | A binary digit: 0 or 1. |
| Byte | A group of 8 bits. |
| Encoding | A rule for representing information as bytes or another agreed form. |
| Unicode | A standard assigning code points to characters across writing systems. |
| Pixel | A smallest addressable picture element in a raster image. |
| Sampling rate | Number of audio samples captured per second. |
| Frame rate | Number of video frames displayed or processed per second. |
| Tensor | A general n-dimensional array used in machine learning. |
| Token | A unit produced by a tokenizer; it may be a character group, word part or other unit. |
| Token ID | An integer identifier assigned to a token in a model vocabulary. |
| Embedding | A learned numerical vector representing an item such as a token, image or audio segment. |
| Feature | A measurable input attribute used by a model. |
| Model parameter | A value learned during training, such as a weight or bias. |
| Training | Updating model parameters using data and an optimization procedure. |
| Inference | Using a trained model to produce predictions or outputs. |
| Attention | A mechanism that computes how strongly elements in a sequence should influence one another. |
| Transformer | A neural-network architecture built around attention and feed-forward blocks. |
| LLM | A large language model trained to process and generate language. |
| VLM | A vision-language model that works with visual information and language. |
| RAG | Retrieval-augmented generation: retrieving relevant external information before generating an answer. |
| Chunk | A smaller segment created from a larger document for processing or retrieval. |
| Vector database | A system designed to store and search vector representations. |
| API | A defined interface through which software components communicate. |
| FastAPI | A Python framework for building APIs. |
| Latency | Time taken for an operation or response. |
| Hallucination | An output that is unsupported or factually incorrect despite being presented confidently. |

> Keep definitions concise here. Link to the full topic page for detailed explanations.
