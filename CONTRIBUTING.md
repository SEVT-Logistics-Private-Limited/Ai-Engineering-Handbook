# Contributing and Conventions

How this handbook is written and organised, so new topics stay consistent.

## Repository layout

| Path | Contents |
|---|---|
| `docs/NN-chapter-name/` | One folder per chapter. `README.md` is the chapter overview (or the topic itself for single-topic chapters). |
| `docs/NN-chapter-name/NN-topic-name.md` | One file per topic |
| `examples/<chapter_name>/` | Runnable Python for each chapter (`snake_case`) |
| `examples/tests/` | Tests that run every example |
| `projects/<project-name>/` | Real projects, with their own `images/` |
| `assets/images/` | Figures generated by `scripts/generate_figures.py` |
| `scripts/` | Tooling: figure generation, link checking |

## Topic page template

Every topic page uses these sections, in this order:

```markdown
# Topic Name

> One-sentence summary.

| | |
|---|---|
| **Chapter** | … |
| **Prerequisites** | … |
| **Example code** | … |
| **Used in project** | … |

## Introduction
## What is it?
## Why is it needed?
## How does it work?
## Architecture            <!-- Mermaid diagram(s) -->
## Practical implementation
## Code example            <!-- snippet + run command + real output -->
## Real-world use cases    <!-- include "In my project" where it applies -->
## Common mistakes and best practices
## Key takeaways

---
**Previous:** … · [Chapter overview](README.md) · **Next:** …
```

## Rules

- **Accuracy first.** Never describe project usage the code doesn't have. Every number in an output block must come from actually running the example.
- **Runnable code.** Every example must pass `pytest examples/tests`.
- **Figures are generated, not hand-made.** Change `scripts/generate_figures.py` and re-run it rather than editing PNGs.
- **Relative links only** within the repository, so it works on GitHub and in clones.
- **Mermaid:** quote labels that contain punctuation, and avoid `<` and `>` in labels.
- Keep formatting plain: no decorative emojis, and tables over long lists where possible.

## Before opening a pull request

```bash
pytest examples/tests -q            # examples run and match the docs
python scripts/check_links.py       # internal links, anchors and images resolve
python scripts/generate_figures.py  # only if examples or figures changed
```
