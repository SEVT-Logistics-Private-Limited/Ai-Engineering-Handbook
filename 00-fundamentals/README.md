# 00 — Fundamentals

Start here even if your goal is to build LLM applications. Understanding computing and data representation makes later AI concepts much easier.

## Learning sequence

1. **What is information and data?** Data is a recorded representation; information is data interpreted in context.
2. **Analog vs digital:** Continuous physical quantities versus discrete encoded values.
3. **Bits and bytes:** The basic units used to represent digital information.
4. **Binary and number systems:** How values are represented and manipulated.
5. **How a computer works:** CPU, memory, storage, input/output and operating systems.
6. **Files and formats:** Bytes plus conventions that define how to interpret them.
7. **Programs and algorithms:** Instructions and procedures that transform inputs into outputs.
8. **What is AI?** Systems performing tasks associated with capabilities such as perception, language or decision-making.
9. **AI vs ML vs deep learning:** Related but not interchangeable terms.
10. **Training vs inference:** Learning parameters from data versus using learned parameters.

## A useful mental model

Real-world signal or content → digital capture/encoding → bytes stored in a file or stream → decoding and preprocessing → numerical model input → computation → output representation → application response.

This is a conceptual overview; each modality and model has its own pipeline.

## Core distinctions

| Concept | Meaning |
|---|---|
| Data | Recorded values or observations |
| Information | Meaning interpreted from data |
| File format | Rules for organizing and interpreting file bytes |
| Algorithm | A defined sequence of computational steps |
| AI | Broad field of building systems that perform intelligent tasks |
| ML | Methods that learn patterns from data |
| Deep learning | ML using multi-layer neural networks |
| Generative AI | Models that generate new content |

## Recommended first exercises

- Convert a small integer to binary and back.
- Inspect a text file as UTF-8 bytes.
- Compare a PNG and JPEG of the same image.
- Record a short audio clip and inspect its sample rate and duration.
- Extract a few frames from an MP4 and inspect their dimensions.
