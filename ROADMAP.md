# AI Engineering Roadmap

This roadmap moves from computer fundamentals to production AI systems. Complete prerequisites before advanced modules, but revisit topics as project needs arise.

## Phase 0 — Computing and AI foundations
- [ ] What information/data is; analog vs digital information
- [ ] Bits, bytes, binary, number systems and memory
- [ ] How a computer stores and processes information
- [ ] Files, formats, compression and metadata
- [ ] What programming, algorithms and APIs are
- [ ] AI vs ML vs deep learning vs generative AI
- [ ] Training, validation, testing and inference

**Exit check:** Explain how a digital file is represented and how a trained model differs from a program of hand-written rules.

## Phase 1 — Data modalities
- [ ] Text: characters, Unicode, encodings, documents
- [ ] Images: pixels, channels, dimensions, color spaces
- [ ] Audio: sound waves, sampling, quantization, channels
- [ ] Video: frames, frame rate, timestamps, codecs and audio tracks
- [ ] Structured, semi-structured and unstructured data
- [ ] Multimodal data and synchronization

**Exit check:** Draw the path from a raw text/image/audio/video file to a numerical representation a model can consume.

## Phase 2 — Data processing and representations
- [ ] Encoding/decoding, serialization and compression
- [ ] Cleaning, normalization, resizing, filtering and augmentation
- [ ] Tokenization and token IDs
- [ ] Dense vectors, embeddings and feature representations
- [ ] Train/validation/test splits and data leakage
- [ ] Batching, padding, masking and data pipelines

**Exit check:** Explain why different modalities need different preprocessing and representations.

## Phase 3 — Machine learning
- [ ] Supervised, unsupervised and reinforcement learning
- [ ] Features, labels, parameters and loss
- [ ] Regression, classification and clustering
- [ ] Overfitting, underfitting, regularization and generalization
- [ ] Metrics, validation and error analysis

## Phase 4 — Deep learning
- [ ] Tensors, dimensions and matrix operations
- [ ] Neurons, layers and neural networks
- [ ] Activation functions and loss functions
- [ ] Forward pass, backpropagation and gradient descent
- [ ] Optimizers, learning rates and normalization
- [ ] CNNs, RNNs, sequence models and Transformers

## Phase 5 — Modality-specific AI
- [ ] NLP and language models
- [ ] LLM architecture, training and inference
- [ ] Computer vision, classification, detection and segmentation
- [ ] Audio classification, speech recognition and speech generation
- [ ] Video understanding and temporal modeling
- [ ] VLMs and multimodal models

## Phase 6 — Generative AI
- [ ] Autoregressive generation
- [ ] Prompt design and structured outputs
- [ ] GANs, VAEs and diffusion models
- [ ] Sampling, decoding, temperature, top-k and top-p
- [ ] Fine-tuning, adapters and quantization

## Phase 7 — RAG and knowledge systems
- [ ] RAG motivation and architecture
- [ ] Ingestion, parsing and chunking
- [ ] Embedding models and vector indexes
- [ ] Similarity search, metadata filters and hybrid retrieval
- [ ] Reranking, context assembly and grounded generation
- [ ] Evaluation, citations, latency and failure analysis

## Phase 8 — Agents and tool use
- [ ] Tool/function calling
- [ ] Agent loops, planning and state
- [ ] Memory and retrieval
- [ ] Workflow orchestration and multi-agent patterns
- [ ] Guardrails, permissions and human approval

## Phase 9 — AI engineering and production
- [ ] Python, OOP, data structures and testing
- [ ] HTTP, REST, JSON and FastAPI
- [ ] SQL, relational databases and vector stores
- [ ] Docker, CI/CD and deployment
- [ ] Observability, tracing, evaluation and monitoring
- [ ] Security, privacy, reliability and cost management
- [ ] Scaling, caching, queues and system design

## Phase 10 — Project evidence and interview readiness
- [ ] Document each project with architecture and data flow
- [ ] Link topics to exact implementation files and tests
- [ ] Record decisions, alternatives, limitations and lessons
- [ ] Prepare concise and deep interview explanations
- [ ] Keep claims aligned with demonstrable evidence

## Suggested study loop
For each topic: learn prerequisites → explain it in your own words → draw the flow → implement a small example → test edge cases → connect it to a project (if genuinely used) → write interview questions → add references.
