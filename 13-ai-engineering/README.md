# 13 — AI Engineering

This module covers the software engineering needed to turn models and AI workflows into dependable applications.

## Programming foundations
- Python syntax, functions, modules, exceptions and typing
- OOP, data structures, algorithms and complexity
- Virtual environments, dependency management and packaging
- Logging, configuration and secrets handling

## APIs and backend systems
- HTTP methods, status codes, headers and JSON
- REST API design, validation and error handling
- FastAPI routes, request/response models and dependency injection
- Authentication, authorization, rate limits and CORS
- Synchronous vs asynchronous operations and background tasks

## Data and storage
- SQL and relational modeling
- Transactions, indexes and query planning
- Document databases and object storage
- Vector indexes, metadata filters and lifecycle management

## Model serving and operations
- Model loading, batching and inference endpoints
- Docker and container fundamentals
- CI/CD and automated tests
- Cloud deployment and environment configuration
- Monitoring, structured logs, traces and metrics
- Latency, throughput, concurrency and cost
- Caching, queues, retries and fault tolerance

## AI-specific reliability
- Evaluation datasets and regression tests
- Prompt/model versioning
- Hallucination and grounding checks
- Input validation and output constraints
- Privacy, data retention and access control
- Human review for consequential actions

## Practical API flow
Client → HTTP request → API validation/authentication → application service → retrieval/model call → response validation → HTTP response.

Document the exact architecture and technologies used in each project; this page is a curriculum, not a claim that every technology has been used.
