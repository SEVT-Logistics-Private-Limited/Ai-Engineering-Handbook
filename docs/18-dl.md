# 18. DL (Deep Learning)

> Deep Learning is a subset of ML that uses multi-layer neural networks to learn complex patterns.

## Introduction

Deep Learning is the part of ML behind LLMs, image recognition and voice assistants. This page also covers how a deep learning model is trained: epochs, batches and the training loop.

## What is it?

**Deep Learning** is a **subset of ML** that primarily uses **multi-layer neural networks** to learn complex patterns.

Example: give a model thousands of face images. It learns features such as eyes, nose, facial shape and so on by itself, and can then recognise a new image.

Examples: self-driving cars, image generation, voice recognition.

## Why is it needed?

Simple ML can't handle very complex data like images, speech and language. Deep neural networks with many layers can learn these complex patterns.

## How does it work?

### Training terms

**Epoch:** one complete pass through the entire training dataset.
- Training samples = 1000
- If the model sees all 1000 samples once → **1 epoch**
- If it sees all 1000 samples 5 times → **5 epochs**

**Batch:** a subset of the training data processed together in one training step (update).
- Dataset = 1000 samples, batch size = 100
- Batch 1 → samples 1–100
- Batch 2 → samples 101–200
- …
- Batch 10 → samples 901–1000
- So **1 epoch = 10 batches = 10 steps**

**Batch size:** the number of training examples processed before an optimizer update.

| Small batch | Large batch |
|---|---|
| Less memory | More memory |
| Can be slower per epoch | Can be computationally efficient on suitable hardware |

### How everything connects

1. **Training data** goes into the **neural network**
2. **Forward propagation** gives a **prediction**
3. The **loss function** measures how wrong the prediction is (the **loss**)
4. **Backpropagation** calculates the **gradients**
5. The **optimizer** **updates the weights and bias**
6. Move to the **next batch**, and after all batches, the **next epoch**
7. **Repeat** until the model is better

## Flow diagram

```text
Training data
      ↓
Neural network
      ↓
Forward propagation
      ↓
Prediction
      ↓
Loss function
      ↓
Loss
      ↓
Backpropagation
      ↓
Gradients
      ↓
Optimizer → update weights and bias → next batch → repeat (next epoch)
```

## Real-world use cases

- Self-driving cars
- Image generation
- Voice recognition
- LLMs like ChatGPT and Gemini

**In my project:** I trained my own deep learning language models with exactly this loop, in PyTorch, on a GPU ([tiny-llm-jetson](https://github.com/SEVT-Logistics-Private-Limited/tiny-llm-jetson)).

## Key takeaways

- Deep Learning = ML with multi-layer neural networks.
- Epoch = one full pass over the data. Batch = a small part of it.
- Training loop: forward → loss → backpropagation → gradients → optimizer update → repeat.
