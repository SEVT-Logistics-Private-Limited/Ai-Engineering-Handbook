# 16. ML (Machine Learning)

> Machine Learning is a subset of AI where systems learn patterns from data instead of relying entirely on explicitly programmed rules.

## Introduction

To understand ML, start with AI.

**AI (Artificial Intelligence)** is the broad field of **building systems that can perform tasks that normally require some form of human intelligence**. Examples: ChatGPT, self-driving cars, Siri.

ML is one way of building AI.

## What is it?

**ML (Machine Learning)** is a **subset of AI where systems learn patterns from data**, rather than relying entirely on explicitly programmed rules.

| | Meaning | Examples |
|---|---|---|
| AI | The broadest concept: systems performing intelligent tasks | ChatGPT, self-driving cars, Siri |
| ML | Systems that learn patterns from data | Fraud detection, stock price prediction, house price prediction |

## Why is it needed?

Some problems are too complex to write rules for by hand. For example, you can't write an `if` statement for every kind of fraud. ML lets the computer **learn the rules from examples**.

## How does it work?

1. Collect data (for example, past house sales with their prices).
2. The ML model looks at the data and **learns the pattern** (size, location → price).
3. Give it new data, and it **predicts** the answer (the price of a new house).

## Flow diagram

```text
AI   (broadest: systems performing intelligent tasks)
 └── ML   (systems learn patterns from data)
      └── Deep Learning   (multi-layer neural networks)
```

```text
Data → ML model learns patterns → New input → Prediction
```

## Real-world use cases

- Fraud detection
- Stock price prediction
- House price prediction
- Recommendations (movies, products)

## In our project

**Used.** Our project mixes the two approaches, which shows the difference between rules and ML clearly:

| Part of the project | Approach |
|---|---|
| Instant replies for time, date and greetings | **Fixed rules** (keyword lookup table) |
| Telugu language model | **ML:** learned Telugu patterns from 50,000 real sentences (`ai4bharat/samanantar`) |
| Conversational Telugu model | **ML:** fine-tuned on 93,028 Telugu samples (`maya-research/IndicVault`) |
| Embedding model for RAG | **ML:** a pretrained model that learned meaning from data |
| Gemini answers | **ML:** a huge pretrained model |

```text
Simple, predictable question ("what time is it?") → rules → instant answer
Open question ("when to change engine oil?")      → ML models (embeddings + LLM) → answer
```

Using rules for the simple cases keeps those answers **instant (under 100 ms)** and saves LLM calls.
