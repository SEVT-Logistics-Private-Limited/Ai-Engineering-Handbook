1. Open each link → select all → copy, or use ChatGPT **Settings → Data controls → Export** (`conversations.json`).
2. Save as `notes/chatgpt-session-1.md` (2, 3 …).
3. Map each concept to a `docs/` page and merge in anything the page is missing.
